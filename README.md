# 基于高云 FPGA 的车载智能格栅多模态驱虫控制系统

> 全国大学生嵌入式芯片与系统设计竞赛 2026 · FPGA 创新设计赛道 · 选题四（开放型题目）
> 主控芯片：高云 GW2A-LV55PG484C8/I7（GW2A-55）  开发平台：J280 姿态控制系统竞赛套件

## 一、项目简介

本项目以高云 GW2A 系列 FPGA 为**唯一控制核心（不使用 MCU/软核）**，针对夜间行车飞虫聚集车头、
干扰视野与散热的痛点，构建"声学驱避 + 光学干扰 + 气流导流"三重协同的多模态智能驱虫系统。

系统依托 FPGA 全硬件并行架构，实现多路超声波 PWM 同步驱动、585nm 黄光 LED 无级调光、
主动进气格栅角度闭环控制三大执行模块的微秒级协同运行，并结合车速信号完成查表式高速气流补偿，
有效缓解 80~120km/h 工况下超声波衰减问题。

## 二、硬件映射（J280 平台）

| 功能 | J280 板载资源 |
|------|--------------|
| 主动格栅驱动电机 + 位置反馈 | TB6612FNG + MG531 直流减速电机 + 霍尔编码器 |
| 格栅叶片角度传感器 | WDD35D4 角位移传感器 + 3PA1030 ADC |
| 4 路驱虫 PWM 输出（演示） | 核心板 LED（实际接超声波/灯板驱动） |
| 上位机监测与调参 | CH340 USB 转串口（115200） |

## 四、编译与烧录

1. 安装高云云源软件 Gowin_V1.9.12.03（或更新版本）；
2. 工程放到**非中文路径**，双击 `grille_repel.gprj` 打开；
3. 点击 "Run all" 完成综合、布局布线；
4. Programmer 打开生成的 `.fs` 文件，SRAM 模式烧录。

## 五、操作说明

| 按键 | 功能 |
|------|------|
| SW1 | 飞虫密度等级递增（0 无 → 1 少 → 2 中 → 3 多） |
| SW2 | 车速等级递增（模拟 0/400/800/1200 编码器计数值） |
| SW3 | 驱虫使能开关 |
| SW4 | 复位到待机 |
| SW5 (rst_n) | 硬件复位 |

演示：SW1 切到密度 2/3，SW3 开启，可见 pwm_out 两路高频（超声波）与两路低频（LED 调光）PWM 输出，
格栅电机转动至导流角。

## 六、串口协议（115200, 8N1）

**遥测（每 10ms 一帧，10 字节）**

```
0xAA | density | speed_level | state | pos[15:8] | pos[7:0]
     | ultra_duty[15:8] | ultra_duty[7:0] | led[15:8] | led[7:0]
```

**调参（4 字节）**：`0xBB | 索引 | 值[15:8] | 值[7:0]`，索引 0=KP、1=KD（格栅 PID 增益，Q8 定点）。

## 七、关键参数标定

1. **格栅角度**：`repel_fsm.v` 中 `GR_HOME/GR_30/GR_45` 为格栅原厂/30°/45° 对应的编码器值（默认
   10000/11000/11500），需据实标定。
2. **车速阈值**：`comp_lut.v` 中 `TH1/TH2/TH3` 为车速等级阈值，需据实标定。
3. **PID 增益**：默认 KP=13.0、KD=2.0（Q8），可通过 UART 在线整定。
